# 📚 MangaVerse - Manga & Manhwa Reader Web Application

เว็บแอปพลิเคชันสำหรับอ่านมังงะ (Manga) และมังฮวา (Manhwa / Webtoon) สไตล์โมเดิร์น สวยงาม ใช้งานง่าย รองรับทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ พร้อมระบบหลังบ้านสำหรับผู้ดูแลระบบ (Admin)

---

## ✨ ฟีเจอร์เด่นของระบบ

### 👥 1. สำหรับผู้อ่านทั่วไป (Public Readers / Guests)
- **เข้าอ่านได้ทันที ไม่ต้องล็อกอิน**: ผู้ใช้งานทั่วไปสามารถเปิดเว็บเข้ามาอ่านได้โดยตรง
- **ความปลอดภัย**: ป้องกันไม่ให้บุคคลทั่วไปสามารถเพิ่ม ลบ หรือแก้ไขเนื้อหาใดๆ ในระบบได้ (Read-Only)
- **โหมดการอ่าน 2 สไตล์ (Dual-Mode Reader)**:
  - 📱 **Webtoon Scroll Mode**: เลื่อนอ่านลงมาต่อเนื่องแบบไร้รอยต่อ เหมาะกับมังฮวาเกาหลี/เว็บตูน
  - 📖 **Manga Paged Mode**: อ่านทีละหน้า มีปุ่มเปลี่ยนหน้า และรองรับการกดลูกศรคีย์บอร์ด ซ้าย/ขวา หรือ Spacebar
- **ปรับแต่งการแสดงผล**: ปรับขนาดความกว้างหน้าจอ (แคบ, ปานกลาง, กว้าง, เต็มจอ) และปุ่ม Fullscreen
- **ค้นหาและคัดกรอง**: ค้นหาตามชื่อเรื่อง ผู้แต่ง หรือเลือกกรองตามประเภท (มังงะ/มังฮวา), หมวดหมู่ (Action, Fantasy ฯลฯ) และสถานะ (กำลังอัปเดต/จบแล้ว)
- **ระบบคั่นหน้า (Bookmarks) & ประวัติการอ่าน (History)**: บันทึกตอนที่อ่านค้างไว้ลงในเครื่องอัตโนมัติ

### 👑 2. สำหรับผู้ดูแลระบบ (Admin Panel)
- **สิทธิ์การเข้าถึง**:
  - **ชื่อผู้ใช้ (Username)**: `prct`
  - **รหัสผ่าน (Password)**: `prct2522`
- **ระบบยืนยันตัวตน (Authentication)**: ป้องกัน API ทุกคำสั่งด้วย Session Token และ HTTP-only Cookie
- **การจัดการเรื่อง (Manga & Manhwa Management)**:
  - เพิ่มเรื่องใหม่ (ชื่อเรื่อง, เรื่องย่อ, ผู้แต่ง, ผู้วาด, ประเภท, หมวดหมู่)
  - รองรับการใส่ URL รูปภาพปก หรือกดปุ่ม **อัปโหลดรูปภาพปกจากเครื่องคอมพิวเตอร์**
  - แก้ไขข้อมูลเรื่อง และลบเรื่อง
- **การจัดการตอน (Chapter Management)**:
  - เพิ่มตอนใหม่ ระบุเลขตอนและชื่อตอน
  - ใส่รูปภาพหน้าการ์ตูน:
    - **วิธีที่ 1**: วางลิงก์ URL รูปภาพ (1 บรรทัดต่อ 1 หน้า)
    - **วิธีที่ 2**: **อัปโหลดไฟล์รูปภาพหลายๆ ไฟล์พร้อมกัน (Multi-file / Drag & Drop)** จากเครื่องขึ้นเซิร์ฟเวอร์
  - พรีวิวภาพทุกหน้าก่อนบันทึก พร้อมปุ่มลบหน้าที่ไม่ต้องการ หรือจัดลำดับ
  - แก้ไขและลบตอน

## 🚀 วิธีการติดตั้งและเปิดใช้งาน

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `run.bat` (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์ `run.bat` ในโฟลเดอร์ ระบบจะค้นหา Node.js และเปิดหน้าเว็บที่ `http://127.0.0.1:5000` ให้อัตโนมัติ

### วิธีที่ 2: รันผ่านคำสั่ง Terminal (Node.js)
```bash
node server.js
```
เปิดเบราว์เซอร์แล้วไปที่: [http://127.0.0.1:5000](http://127.0.0.1:5000)

## 📁 โครงสร้างโปรเจกต์

```text
├── data/
│   └── manga_data.json       # ข้อมูลมังงะ ตอน และประวัติ (บันทึกอัตโนมัติ)
├── wwwroot/                  # ไฟล์ Frontend Web Application
│   ├── css/
│   │   └── style.css         # ดีไซน์ Dark Theme ระดับพรีเมียม
│   ├── js/
│   │   ├── api.js            # API Client + Authentication Token
│   │   └── app.js            # ระบบควบคุม SPA, Viewer, Filters, Admin
│   ├── uploads/              # โฟลเดอร์เก็บรูปภาพที่แอดมินอัปโหลด
│   │   ├── covers/           # รูปภาพหน้าปก
│   │   └── chapters/         # รูปภาพหน้าการ์ตูนแต่ละตอน
│   └── index.html            # โครงสร้างหน้าเว็บหลัก (SPA)
├── server.js                 # HTTP & REST API Server (Node.js)
├── Program.cs                # ASP.NET Core Web API (.NET 10)
├── MangaReaderApp.csproj     # .NET Project Configuration
├── run.bat                   # สคริปต์รันเซิร์ฟเวอร์แบบคลิกเดียว
└── README.md                 # คู่มือการใช้งานระบบ
```
