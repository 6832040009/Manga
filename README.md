# 📚 MangaVerse - Manga & Manhwa Reader Web Application

เว็บแอปพลิเคชันสำหรับอ่านมังงะ (Manga) และมังฮวา (Manhwa / Webtoon) สไตล์โมเดิร์น สวยงาม ใช้งานง่าย รองรับทั้งบนคอมพิวเตอร์ แท็บเล็ต และโทรศัพท์มือถือ พร้อมระบบหลังบ้านสำหรับผู้ดูแลระบบ (Admin)

---

## ✨ ฟีเจอร์เด่นของระบบ

### 👥 1. สำหรับผู้อ่านทั่วไป (Public Readers / Guests)
- **เข้าอ่านได้ทันที ไม่ต้องล็อกอิน**: ผู้ใช้งานทั่วไปสามารถเปิดเว็บเข้ามาอ่านได้โดยตรง
- **ความปลอดภัย**: ป้องกันไม่ให้บุคคลทั่วไปสามารถเพิ่ม ลบ หรือแก้ไขเนื้อหาใดๆ ในระบบได้ (Read-Only)
- **โหมดการอ่าน 2 สไตล์ (Dual-Mode Reader)**:
  - 📱 **Webtoon Scroll Mode**: เลื่อนอ่านลงมาต่อเนื่องแบบไร้รอยต่อ เหมาะกับมังฮวาเกาหลี/เว็บตูน
  - 📖 **Manga Paged Mode**: อ่านทีละหน้า มีปุ่มเปลี่ยนหน้า และรองรับการกดลูกศรคีย์บอร์ด ซ้าย/ขวา หรือ Spacebar
- **ปรับแต่งการแสดงผล**: ปรับขนาดความกว้างหน้าจอ (แคบ, ปานกลาง, กว้าง, เต็มจอ) และปุ่ม Fullscreen
- **ค้นหาและคัดกรอง**: ค้นหาตามชื่อเรื่อง ผู้แต่ง หรือเลือกกรองตามประเภท (มังงะ/มังฮวา), หมวดหมู่ (Action, Fantasy ฯลฯ) และสถานะ (กำลังอัปเดต/จบแล้ว)
- **ระบบคั่นหน้า (Bookmarks) & ประวัติการอ่าน (History)**: บันทึกตอนที่อ่านค้างไว้ลงในเครื่องอัตโนมัติ

  - **รหัสผ่าน (Password)**: `prct2522`

- **การจัดการเรื่อง (Manga & Manhwa Management)**:
  - เพิ่มเรื่องใหม่ (ชื่อเรื่อง, เรื่องย่อ, ผู้แต่ง, ผู้วาด, ประเภท, หมวดหมู่)
  - รองรับการใส่ URL รูปภาพปก หรือกดปุ่ม **อัปโหลดรูปภาพปกจากเครื่องคอมพิวเตอร์**

    - **วิธีที่ 2**: **อัปโหลดไฟล์รูปภาพหลายๆ ไฟล์พร้อมกัน (Multi-file / Drag & Drop)** จากเครื่องขึ้นเซิร์ฟเวอร์
  - พรีวิวภาพทุกหน้าก่อนบันทึก พร้อมปุ่มลบหน้าที่ไม่ต้องการ หรือจัดลำดับ
  - แก้ไขและลบตอน

## ☁️ วิธีการ Deploy บน AWS EC2 (ดึงโค้ดผ่าน GitHub)

### ขั้นตอนที่ 1: ตั้งค่า AWS Security Group (บน AWS Console)
ก่อนเริ่ม ให้เข้าไปที่ **AWS EC2 Console** -> **Security Groups** ของ Instance ที่เช่าไว้ แล้วเปิด **Inbound Rules**:
| Type | Protocol | Port Range | Source | คำอธิบาย |
| :--- | :--- | :--- | :--- | :--- |
| **SSH** | TCP | `22` | `0.0.0.0/0` (หรือ My IP) | สำหรับเชื่อมต่อเข้าเซิร์ฟเวอร์ |
| **HTTP** | TCP | `80` | `0.0.0.0/0` | สำหรับให้ผู้ใช้ทั่วไปเข้าเว็บ |
| **HTTPS** | TCP | `443` | `0.0.0.0/0` | สำหรับ SSL / HTTPS (ถ้ามี) |

---

### ขั้นตอนที่ 2: เชื่อมต่อ SSH เข้าเครื่อง AWS
เปิดโปรแกรม Terminal หรือ PowerShell ในคอมพิวเตอร์ของคุณ:
```bash
ssh -i "your-key.pem" ubuntu@<YOUR-AWS-PUBLIC-IP>
```
*(ถ้าใช้ Amazon Linux ให้เปลี่ยน `ubuntu` เป็น `ec2-user`)*

---

### ขั้นตอนที่ 3: สั่ง Deploy อัตโนมัติในคำสั่งเดียว (One-Click Deploy)
รันคำสั่งนี้บนเครื่อง AWS Terminal:

```bash
curl -fsSL https://raw.githubusercontent.com/6832040009/Manga/main/deploy.sh | bash
```

**สิ่งที่สคริปต์จะทำให้โดยอัตโนมัติ:**
1. ติดตั้ง Node.js 20 LTS, Git, PM2 และ Nginx
2. Clone โค้ดล่าสุดจาก GitHub (`https://github.com/6832040009/Manga.git`) ไปไว้ที่ `/var/www/manga`
3. ตั้งค่า PM2 ให้เซิร์ฟเวอร์เปิดทำงานตลอดเวลา 24/7 และเปิดใหม่อัตโนมัติเมื่อเครื่อง Restart
4. ตั้งค่า Nginx Reverse Proxy (Port 80 -> Port 5000)
5. เปิด Firewall และแสดง URL พร้อมใช้งานทันที!

---

### หรือ วิธีที่ 4: Deploy ด้วย Docker (ทางเลือก)
หากเครื่อง AWS มี Docker ติดตั้งอยู่แล้ว สามารถรันด้วย Docker Compose ได้ทันที:
```bash
git clone https://github.com/6832040009/Manga.git
cd Manga
sudo docker compose up -d --build
```

## 🛠️ คำสั่งการจัดการบนเซิร์ฟเวอร์ AWS (เมื่อต้องการอัปเดต)

- **อัปเดตโค้ดเวอร์ชันล่าสุดจาก GitHub**:
  ```bash
  cd /var/www/manga
  git pull origin main
  pm2 reload manga-app
  ```
- **ดูบันทึกการทำงาน (Logs)**:
  ```bash
  pm2 logs manga-app
  ```
- **ตรวจสอบสถานะเซิร์ฟเวอร์**:
  ```bash
  pm2 status
  ```
- **รีสตาร์ทแอปพลิเคชัน**:
  ```bash
  pm2 restart manga-app
  ```
